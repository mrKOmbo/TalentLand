# 📱 Guía de Accesibilidad Visual - Atenea

## 🚀 Inicio Rápido (3 Pasos)

### 1️⃣ Crear Cuenta con Accesibilidad Visual
```
Registro → Llenar datos → Selector "Accesibilidad" → Elegir "Visual" → Crear cuenta
```
✅ Escucharás: "Bienvenido a Atenea, tu perfil de accesibilidad ha sido configurado"

### 2️⃣ Configurar Preferencias
```
Menú lateral (☰) → Accesibilidad → Activar opciones que necesites
```

### 3️⃣ ¡Usar la App!
Todo está listo. Las funcionalidades se activarán automáticamente según tu configuración.

---

## ⚙️ Opciones de Configuración

### 🎨 **Alto Contraste**
- **Qué hace:** Colores más intensos, mejor visibilidad
- **Activar:** Configuración → Toggle "Modo de Alto Contraste"
- **Resultado:** Fondo negro, textos más nítidos

### 📏 **Tamaño de Texto**
- **Qué hace:** Agranda o reduce todo el texto
- **Activar:** Configuración → Deslizar control de "Tamaño de Texto"
- **Rango:** 80% a 250%

### 🔊 **VoiceOver (Lectura de Pantalla)**
- **Qué hace:** Lee todo en voz alta
- **Activar:** Configuración → Toggle "VoiceOver"
- **Niveles:** Breve / Normal / Detallado
- **Idioma:** Español (México)

### 🗣️ **Navegación por Audio**
- **Qué hace:** Instrucciones habladas al navegar
- **Activar:** Configuración → Toggle "Navegación por Audio"
- **Ejemplo:** "Iniciando navegación a Estadio Azteca. Distancia: 2.5 kilómetros"

### 📳 **Feedback Háptico**
- **Qué hace:** Vibraciones al interactuar
- **Activar:** Configuración → Toggle "Feedback Háptico"
- **Cuándo vibra:** Botones importantes, dirección correcta, llegada a destino

### 🎨 **Modo de Daltonismo**
- **Qué hace:** Ajusta colores según tu tipo de daltonismo
- **Activar:** Configuración → Selector "Modo de Color"
- **Opciones:** Protanopía, Deuteranopía, Tritanopía, Acromatopsia

## 🧭 Funcionalidades en Uso

### 📍 **Navegar en el Mapa**
```
1. Selecciona un destino
2. Presiona "Iniciar navegación"
3. Escucharás instrucciones en voz alta
4. Recibirás actualizaciones cada 30 segundos
```

**Con VoiceOver activo:**
- Escucharás nombre, categoría y distancia de lugares
- Anuncios automáticos al cambiar de pantalla

### 🔍 **Realidad Aumentada (AR)**
```
1. Entra a navegación AR
2. Apunta la cámara al frente
```

**Funcionalidades AR:**

#### 📄 Detección de Texto
- **Automática** - No necesitas hacer nada
- Aparece cuadrito abajo con el texto detectado
- Funciona con letreros, señales, carteles

#### ✅ Dirección Correcta
- Cuando apuntes en la dirección correcta (±15°):
  - 📳 Vibra una vez
  - 🟢 Aparece badge verde "¡Dirección correcta!"
  - 🔆 Borde verde brillante en botones

#### 👁️ Ocultar/Mostrar Flecha
- Botón arriba a la derecha
- **Ocultar:** Vista limpia, AR sigue activo
- **Mostrar:** Vuelven los overlays de dirección

## 🎯 Escenarios de Uso

### Escenario 1: "Quiero llegar a un lugar"
```
✅ Activa: VoiceOver + Navegación por Audio + Feedback Háptico
📍 Selecciona destino en el mapa
🗣️ Escucharás: instrucciones paso a paso
📳 Sentirás: vibraciones en momentos clave
```

### Escenario 2: "Necesito leer un letrero"
```
📸 Abre navegación AR
🔍 Apunta cámara al letrero
📄 Lee el texto en el cuadrito de abajo
🔊 Si VoiceOver está activo, también lo escucharás
```

### Escenario 3: "Me cuesta ver bien"
```
⚫ Activa: Alto Contraste
📏 Aumenta: Tamaño de Texto a 150-200%
🎨 Ajusta: Modo de Daltonismo (si aplica)
```

### Escenario 4: "Prefiero solo audio"
```
🔊 Activa: VoiceOver + Navegación por Audio
👁️ En AR: Presiona "Ocultar flecha"
🎧 Navega solo escuchando instrucciones
```

## 💡 Consejos

### ✅ **Recomendaciones**
- Empieza con configuración básica (Alto Contraste + Texto grande)
- Prueba VoiceOver en ambiente silencioso primero
- Usa AR con buena iluminación
- Prueba el botón de test para confirmar que todo funciona

### ❌ **Evita**
- No actives VoiceOver de iOS (usa el de la app)
- No uses AR en lugares oscuros
- No esperes detectar texto manuscrito (funciona mejor con impreso)

## 🆘 Solución Rápida de Problemas

### **No escucho nada:**
- ✅ Verifica que VoiceOver esté activado en Configuración
- ✅ Sube el volumen del dispositivo
- ✅ Desactiva VoiceOver de iOS (Ajustes → Accesibilidad → VoiceOver)
- ✅ Asegúrate de no tener modo silencio activado

### **No vibra:**
- ✅ Verifica que Feedback Háptico esté activado en Configuración
- ✅ iPhone debe ser 7 o posterior
- ✅ Revisa modo "No molestar"
- ✅ Verifica que el dispositivo tenga motor Taptic Engine

### **No detecta texto en AR:**
- ✅ Apunta a texto claro y grande
- ✅ Mejora la iluminación
- ✅ Mantén el dispositivo estable 2-3 segundos
- ✅ Verifica permisos de cámara (Ajustes → Atenea → Cámara)
- ✅ Funciona mejor con texto impreso que manuscrito

### **No aparece el menú de Accesibilidad:**
- ✅ Verifica que registraste con tipo de discapacidad "Visual" o "Multiple"
- ✅ Cierra sesión y vuelve a entrar
- ✅ Si el problema persiste, registra una nueva cuenta
